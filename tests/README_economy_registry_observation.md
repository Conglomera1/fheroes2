in the SAME frozen frame, AFTER search/stability. Ownership travels with its Result
and ends when Planner's observation returns. Compile/runtime diagnostics opt-in
hook unchanged. No persistent live commitments or executable policy is created.

No registry is made from an unverified/held selection, missing mission evidence,
external retained/active commitments, unsupported transfer or unknown beneficiary.

protected local-town programs; no abandonment authority is inferred from sharing
the chosen plan's funding. Group in first-town-occurrence order; verify exact
chronological operation order after import, including original same-day order.
If grouping changes that order, discard the entire registry rather than partially
adopt a subset. Full source action/project/index -> registry-ID links retained.

Registry import does not independently recertify the score. It uses the schedule
from the same verified Pipeline result and checks structural identity/order; the
registry's fundingVerified stays false. No risk/force/projection/path/search budget
is added or reset, no evaluator called again. No registry view replaces the live
reference. Source plan and contextual limitations remain those of bounded search.

Process-monotonic game-thread token, no RNG/clock or serialized identity. Registry
scope is explicitly hypothetical_snapshot_only. Never carry its unexecuted plans
into the next real turn as retained promises. No ticket or receipt is emitted;
legacy AI did not agree to execute this hypothetical schedule. Matching its later
actions by coincidence would not establish a valid program execution receipt.

live_commitments=false, retained_between_turns=false, actual_receipts=0,
reference_replaced=false, actionable=false. Exact dates/quantities and required
flags logged, all programs protected. Level 0 emits none.
