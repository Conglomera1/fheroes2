KNIGHT MOD 1.1b
Installation manuelle sous Windows

INSTALLATION

Il faut une installation fonctionnelle de fheroes2 1.1.17 ou d’une
version ultérieure, avec les données de Heroes II. Knight Mod utilise
les bibliothèques déjà présentes dans ce dossier.

1. Fermer fheroes2 et Knight Mod. Si le mod a été installé avec
   Knight-Mod-Setup.exe, le désinstaller depuis le menu Démarrer
   avant de passer au ZIP.
2. Choisir l’archive correspondant à l’installation de fheroes2.

   Knight-Mod-1.1b-Windows-x86.zip pour fheroes2 32 bits
   Knight-Mod-1.1b-Windows-x64.zip pour fheroes2 64 bits

3. Extraire le contenu de cette archive dans le dossier qui contient
   fheroes2.exe, en conservant les sous-dossiers. Après extraction,
   KnightModLauncher.exe, fheroes2KM.exe, Uninstall_KM.bat et le
   dossier Knight Mod doivent se trouver à côté de fheroes2.exe. Si
   le dossier est protégé, Windows peut demander une autorisation.

POUR JOUER

Avant la première partie, enregistrer sous un autre nom les
sauvegardes automatiques et rapides de fheroes2 à conserver.
Le mod utilise le même dossier de sauvegarde.

Ouvrir KnightModLauncher.exe. Modifier les réglages si nécessaire,
puis cliquer sur Jouer pour les enregistrer et lancer le mod. Si le
jeu est déjà ouvert, le redémarrer pour appliquer les changements.
Il est aussi possible de créer un raccourci du lanceur sur le Bureau.
Pour lancer le mod directement, ouvrir fheroes2KM.exe.

Les boutons Readme et Guide d’équilibrage du lanceur ouvrent la
documentation. Les deux langues sont aussi disponibles dans
Knight Mod\docs.

  Readme_FR.txt                      Readme en français
  Readme.txt                         Readme en anglais
  Guide_de_Test_et_Equilibrage.pdf    Guide en français
  Testing_and_Balance_Guide.pdf       Guide en anglais

DÉSINSTALLATION PAR BATCH

Fermer le jeu et le lanceur. Exécuter Uninstall_KM.bat depuis le
dossier qui contient fheroes2.exe. Si le dossier est protégé,
faire un clic droit sur le fichier et choisir Exécuter en tant
qu’administrateur.

Appuyer sur Y pour confirmer ou sur N pour annuler. Si des réglages
Knight Mod sont présents, le batch propose de les supprimer.
Appuyer sur N pour les conserver en vue d’une prochaine installation.
Le batch se supprime après avoir retiré les fichiers du mod.

DÉSINSTALLATION MANUELLE

Fermer le jeu et le lanceur. Dans le dossier qui contient
fheroes2.exe, supprimer les éléments de la liste ci-dessous.

  fheroes2KM.exe
  KnightModLauncher.exe
  Uninstall_KM.bat
  Le dossier Knight Mod

Déplacer les éventuels fichiers personnels hors du dossier Knight Mod
avant de le supprimer. Supprimer le raccourci du Bureau s’il a été créé.

Pour effacer aussi les réglages, supprimer knight_mod.ini et
knight_mod_launcher.language dans %APPDATA%\fheroes2, ou dans
%HOME%\.fheroes2 si la variable HOME est définie. Conserver les
sauvegardes et les profils de configuration exportés.
